The Premise

For this assignment, this one guy Prokudin-Gorskii took a bunch of photos. These photos are supposed to be in color. To do this he took three photos, each with a red, green, or blue filter. The original photo looks like this:

It's pretty messy. The borders are inconsistent, and there are a bunch of speckles everywhere. Our job is to line up these 3 images together so it looks pretty and all the colors match up!

The Approach

So how can we line the images up? Well first we have to split the raw image into 3. Once we split them up, we can align them according to the blue image. Then, we create some sort of algorithm to align them. Finally, we can stack the images together and output that as an RGB image.

Thankfully, the starter code does the first and last part for us already. Breaking the image into 3, and stacking them all at the end. I just have to create some sort of algorithm for aligning.

Aligning

Well, how do you align two images? As it suggests in the project page, we iterate through all the pixel displacements and we use some sort of metric to see how well they match. The metric I chose was taking the L2 norm of the difference between the two images (as suggested from the project page). Basically finding how far the images are from each other! We can iterate through all the displacements, save the displacement with the least distance, then output that.

Image Pyramids!

First, let's test our algorithm on one of the bigger images. I chose to do melons.tif, here's what it looks like:

Yikes! It's way off. The reason for this is that theoretically it should work, but the image is so big trying to align it with a displacement > 15 takes a LONG time to run. Even running this with ±15 took ~40s to run. Which is why we have to use an image pyramid. First, we find the alignment of the downscaled image, iterating through a large pixel displacement. Once we find that, we scale the image back up and use the displacement we found before as a base to search from, we can search through a much smaller pixel to fine tune our search.
